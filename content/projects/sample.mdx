# E-Commerce System Analysis

This is a **sample project case study** built with MDX. 

## Business Process Flow

We started by mapping out the "As-Is" process and identifying bottlenecks in the checkout flow.

<VideoEmbed src={frontmatter.VideoUrl} title="Checkout Flow Analysis Video" />

### Key Findings
1. User drop-off at the payment gateway was 15%.
2. Load times during peak hours exceeded 3 seconds.

## Recommendations
* Implement a caching layer using Redis.
* Redesign the UI for mobile responsiveness.
