# Participant | PKM-KC 2026

## Overview

Participated in the **Program Kreativitas Mahasiswa — Karsa Cipta (PKM-KC) 2026**, submitting a technical innovation proposal for an **Expert System-based Food Stock Management Application**. This is the second consecutive year contributing to PKM, building on lessons learned from the 2025 cycle with a stronger technical foundation and a more validated problem statement.

The proposed system targets **small-to-medium food businesses** (warung, UMKM, catering) that struggle with food waste and stock mismanagement due to a lack of data-driven tools accessible at their scale.

## About the Proposed Product

> **Perancangan Aplikasi Manajemen Stok Pangan Berbasis Sistem Pakar**
> *(Design of a Food Stock Management Application Based on an Expert System)*

The application leverages **Expert System (knowledge-based AI)** principles to help business owners make informed purchasing and inventory decisions without needing formal data science expertise.

### Core Features

| Feature | Description |
|---|---|
| **Expert System Engine** | Rule-based AI that recommends order quantities based on sales patterns, expiry dates, and seasonal trends |
| **Smart Reorder Alerts** | Automatic notifications when stock hits critical levels |
| **Waste Tracking** | Logs expired or discarded items to calculate waste cost over time |
| **Demand Prediction** | Forecasts future stock needs based on historical sales data |
| **Simple Dashboard** | Mobile-friendly UI optimized for non-tech-savvy users |

### Technical Architecture
- **Backend**: Python-based expert system with rule-base knowledge engine.
- **Frontend**: Mobile app (Android) using React Native.
- **Database**: Local SQLite with optional cloud sync via Firebase.
- **AI Model**: Forward-chaining inference engine with fuzzy logic for uncertain inputs.
