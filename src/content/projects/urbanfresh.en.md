# UrbanFresh — Automated Laundry Web App

## 📌 Introduction
UrbanFresh is an automated, self-service laundry ordering platform built for both individual (B2C) and corporate (B2B) clients. It marks my first complete full-stack web development project.

## 🎯 Objective
To automate the entire laundry order lifecycle—from customer placement to status updates—without requiring an active human administrator, utilizing a Google Sheets-based backend infrastructure.

## 💡 Background / Why It Exists
Traditional laundry services require customers to physically visit the outlet or call to place orders and check statuses. This creates friction for busy customers and heavy operational overhead for service owners. UrbanFresh was created to solve this by providing 24/7 self-service ordering and automated WhatsApp notifications.

## 🧑‍💼 My Role
As a **Full-Stack Developer**, I designed the user interface, built the front-end web application, and developed the serverless backend utilizing Google Apps Script and Google Sheets.

## ⚙️ Modules Created
The project involved the development of two main areas:
*   **Customer-Facing Modules:** Built order forms for B2C and B2B clients, dynamic service selection (Wash & Fold, Dry Clean, etc.), and real-time order status tracking features.
*   **Admin & Automation Modules:** Integrated a Google Sheets database, built an auto-calculating revenue dashboard, and wrote Apps Script automations to progress order statuses from "New" to "Delivered."
*   **WhatsApp API Integration:** Programmed triggers to send automated order confirmations and status updates directly to customers' WhatsApp numbers.

## 🚀 Impact
The project successfully launched a production-ready laundry platform with zero server operational costs. This automation eliminates the need for manual intervention in routine orders, significantly boosting business efficiency and providing a seamless, modern customer experience.
