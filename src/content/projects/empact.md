## Overview

Empact is a youth community organization dedicated to social impact and personal development. This project involved joining the **UKM Coding front-end team** to convert a professionally designed Figma UI into a fully functional, responsive, and hosted community profile website — delivered within one month for a real client.

---

## The Client

**Empact Community** is an active organization with programs including:
- **Empower 360** — leadership and empowerment workshops
- **Empower Talks** — speaker series with industry professionals
- **Insight E** — educational content and articles
- **Sharing E** — peer-to-peer knowledge sharing sessions
- **Workshop series** — skill-building events (IWD 2025, Bento Cake, etc.)
- **Farewell Party** — annual community celebration
- **Charity programs** — community service initiatives

## Technical Implementation

### Design-to-Code Conversion Process
1. Analyzed the Figma design system — extracted color tokens, typography scales, spacing grid
2. Set up the React + Vite project with Tailwind CSS
3. Built reusable component library matching Figma components exactly
4. Implemented responsive breakpoints (mobile / tablet / desktop)
5. Connected dynamic content (blog posts, team members, gallery) via structured data files
6. Optimized assets (SVG icons, compressed images)
7. Deployed via Vercel with custom domain configuration

### Key Technical Features
- **SVG-first assets** — all illustrations and icons in SVG for perfect scaling
- **React Router** — smooth page transitions without full reloads
- **Lazy loading** — images load on demand to improve initial page speed
- **Mobile-first CSS** — built from smallest breakpoint up
- **Accessible markup** — semantic HTML5 with ARIA labels
