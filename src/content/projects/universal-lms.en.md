# Universal Learning Management System

## 📌 Introduction
The Universal Learning Management System (LMS) is a large-scale front-end template designed to be universally adaptive—capable of serving the educational needs of institutions from elementary schools to universities.

## 🎯 Objective
To provide a highly flexible, role-based LMS platform that operates without relying on heavy external frameworks, ensuring it is lightweight, highly portable, and easily integrated with any back-end system.

## 💡 Background / Why It Exists
Most LMS platforms in the market are built for specific educational levels, forcing institutions to either purchase multiple products or heavily customize existing solutions. This system challenges that constraint with a **"One codebase, every classroom"** philosophy, offering a modular page architecture and configurable terminology to suit any school's needs.

## 🧑‍💼 My Role
As the **Front-End Developer (Solo)**, I was responsible for designing and developing the entire front-end application from scratch, utilizing pure vanilla HTML, CSS, and JavaScript.

## ⚙️ Modules Created
This LMS is built with a component-based architecture and includes the following key modules:
*   **Role-Based Dashboards:** Dedicated and segregated dashboards for Students, Teachers, and Administrators with function-specific widgets.
*   **Core Academic Modules:** Created complete UI modules for Courses (catalog & delivery), Assignments (submission portal), Grades (gradebook), and Schedule.
*   **Operational & Communication Modules:** Developed modules for Attendance marking, Internal Messages, and Institutional Announcements.
*   **Technical Infrastructure:** Implemented CSS Custom Properties for seamless theming/branding and LocalStorage integration to demonstrate stateful functionality without a server.

## 🚀 Impact
This project delivered an ultra-fast (all assets under 200KB), highly accessible (WCAG AA standard), and portable LMS template. It proves that complex educational systems can run exceptionally well and responsively using fundamental web technologies, laying a perfect foundation for back-end integration.
