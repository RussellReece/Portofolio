# UX Research Project: Eatventory (Food Stock App)

## 📌 Introduction
Eatventory is a food stock management application. This specific project focuses on the User Experience (UX) Research phase to ensure the app's design seamlessly integrates with users' daily grocery and consumption habits.

## 🎯 Objective
To deeply understand user behaviors and mindsets regarding food waste, and to design logical user experience solutions through User Journey mapping, Information Architecture, and interactive prototyping.

## 💡 Background / Why It Exists
The issue of food waste is a major hurdle in achieving Zero Hunger. Based on our questionnaire research, 65% of respondents throw away food simply because they let it expire. This app was conceptualized because there is a strong need for an intuitive digital intervention—such as expiration notifications and grocery needs analysis—to alter these consumption habits.

## 🧑‍💼 My Role
As a **UX Researcher**, I played a full role in conducting field research, processing data into User Personas, constructing User Journey Maps, designing the system flowcharts, and building the Hi-Fi user interface prototype in Figma.

## ⚙️ Modules Created
The UX Research and UI design process yielded several key deliverables:
*   **User Persona & Problem Finding:** Analyzed target user profiles (such as university students and seniors) and identified *overstocking* as the core problem.
*   **User Journey Map:** Mapped the user experience into 6 stages: Awareness, Analyzing, Recommendation, Cart & Checkout, Pick-up, and Inventory.
*   **Information Architecture & Flowchart:** Created the sitemap and logical workflows for the stock analysis system, inventory tracker, and AI Expert System chatbot interactions.
*   **UI Design & Prototyping:** Developed a Style Guide (using nature-inspired colors and the Archivo font) and built an interactive prototype from Lo-Fi to Hi-Fi, ready for user testing.

## 🚀 Impact
This project produced a research-validated user interface and interaction design. The resulting UI/UX design offers clear navigation and functional solutions to prevent food waste, serving as a solid blueprint for the subsequent software engineering (coding) phase.
