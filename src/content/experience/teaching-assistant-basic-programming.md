# Teaching Assistant — Pemrograman Dasar

**Peran:** Asisten Dosen (*Teaching Assistant*)  
**Mata Kuliah:** Pemrograman Dasar  
**Timeline:** September 2026 - Sekarang

## Deskripsi Peran

Sebagai Asisten Dosen Pemrograman Dasar, saya mendampingi mahasiswa semester pertama dalam mata kuliah berbobot **4/2 SKS**: 4 SKS perkuliahan dan 2 SKS praktikum. Saya membantu menjelaskan konsep fundamental Java, memandu latihan pemrograman, serta memberikan arahan saat mahasiswa memecahkan masalah di sesi kelas maupun laboratorium.

- Mendukung pelaksanaan sesi perkuliahan dan praktikum secara terstruktur.
- Membimbing mahasiswa dalam memahami sintaks, logika, dan penerapan dasar Java.
- Menjawab pertanyaan teknis dan membantu mahasiswa membangun kepercayaan diri saat menulis serta melakukan *debugging* kode.

## Tantangan & Adaptasi

Pada tahun akademik ini, universitas memperbarui kurikulum mahasiswa semester pertama dengan menambahkan **Oracle Academy Java Foundation**. Materi ini belum tersedia ketika saya menjalani semester pertama, sehingga saya menghadapi tantangan untuk memahami kurikulum baru sambil mengajarkannya.

Untuk beradaptasi, saya **mengikuti dan menyelesaikan materi Oracle Academy secara paralel** dengan kegiatan mengajar. Proses ini membantu saya menguasai materi baru dengan cepat, menerjemahkannya menjadi penjelasan yang mudah dipahami, dan memberikan bimbingan yang relevan kepada mahasiswa. Pengalaman ini menunjukkan kemampuan belajar cepat, fleksibilitas teknis, serta komitmen saya untuk memastikan mahasiswa mendapatkan pendampingan terbaik.
